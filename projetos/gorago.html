GoraGo

Projeto do 1º semestre · Plataforma para busca de vagas de estágio e emprego.

Sobre o projeto

O GoraGo é um site projetado para facilitar a busca por vagas de estágio e emprego. Ele foi desenvolvido como projeto Interdisciplinar do primeiro semestre do curso de DSM da Fatec - Itapira

Objetivo

Aproximar pessoas em busca de oportunidades de trabalho das vagas disponíveis facilitando a busca e fazendo com que o processo de busca e inscrição seja rapido e evite ser repetitivo para o usuários.

Funcionalidades e tecnologias


Linguagens Utilizadas:
  • HTML
  • CSS
  • JavaScript

Funcionalidades:
  • Cadastro de usuários
  • Login e autenticação
  • Busca de vagas
  • Inscrição em vagas
  • Gerenciamento de perfil
